# HUDI-SOFT HMS — Android APK Build Guide

## Prerequisites

| Tool | Version | Install |
|------|---------|---------|
| Node.js | 18+ | https://nodejs.org |
| Java JDK | 17 | https://adoptium.net |
| Android Studio | Latest | https://developer.android.com/studio |
| Android SDK | API 34+ | Via Android Studio → SDK Manager |

Make sure `ANDROID_HOME` / `ANDROID_SDK_ROOT` environment variable is set.

---

## One-time Setup

```bash
# 1. Install dependencies (if not done)
npm install

# 2. Add Android platform (first time only — already removed old android/ folder)
npx cap add android
```

---

## Build Steps (every release)

```bash
# Step 1 — Build the Next.js app as a static export (output goes to /out)
npm run build

# Step 2 — Copy the /out folder into the android project + sync plugins
npx cap sync android

# Step 3 — Generate all Android icon & splash screen sizes from assets/icon.png
npx @capacitor/assets generate --android

# Step 4 — Open in Android Studio to build the APK
npx cap open android
```

In Android Studio:
- **Debug APK**: Build → Build Bundle(s) / APK(s) → Build APK(s)
- **Release APK**: Build → Generate Signed Bundle / APK

## Activation Flow

When the app is installed for the first time:

1. User opens the app → sees the **HUDI SOFT Activation Screen**
2. User enters the **license key** received from HUDI-SOFT
3. The key is verified against the backend license registry
4. On success → activation info (clinic name, start date, expiry date) is saved locally
5. The app redirects to the login screen

### Key behaviour across devices
- If a user copies their license key and activates on another device, **both devices share the same activation date and expiry date** (the dates come from the server, not the device)
- Up to the server's device slot limit applies per key

### Re-activation
- On the "Already Activated" screen, tapping **"Use a Different Key"** clears the stored activation and shows the key entry form again

## Icon

The app icon is the HUDI SOFT circular logo (`assets/icon.png`).  
All icon sizes are generated by `@capacitor/assets generate`.

To update the icon, replace `assets/icon.png` with a square PNG (1024×1024 recommended)
and re-run `npx @capacitor/assets generate --android`.
